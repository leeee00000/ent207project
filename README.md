# 腾冲福溪塔民宿智慧运营平台 (Fuxi Tower Homestay AI Operations Platform)

本项目是专为**腾冲市心灵复苏福溪塔酒店管理有限公司**定制的数字化与智能体决策工作台。针对长尾民宿“弱旺季经营困难”、“OTA客诉处理生硬”、“古镇木建隔音差”等行业痛点，提供模块化、轻量级的系统解决方案。

## 🌟 核心功能矩阵
- **模块 1：弱旺季逆周期策略 Agent**（商圈房态预测 / 动态调价 / 特色打包）
- **模块 2：高情商公关与客诉挽回 Agent**（情绪感知 / 口碑修复 / 争议化解）
- **模块 3：新管家业务实训考核靶场**（AI拟真场景对练 / SOP即时评分）
- **模块 4：智能选房与噪音/交通感知系统**（古镇石板路动线与施工源避噪排房）
- **模块 5：协同生态与集采共享平台**（跨物业供应链协同与资源共享）

## 🛠️ 技术架构
- **前端表现层**：原生 HTML5 + CSS3 + 原生 JavaScript（轻量微交互，移动端与 PC 端自适应）
- **后端服务层**：Python 轻量 Web 服务（监听 8000 端口）
- **认知智能体**：预留对接智谱 AI 开放平台（GLM-4 / GLM-4-Flash 流式对话模型）
- **网络分发层**：SakuraFrp 穿透映射
